# 来源重点覆盖与新闻价值

事实原子是核验单位；一条新闻可包含多个必要事实点。不得把日期和动作准确视为编辑完成，也不设最低字数、固定原子数或统一参数数量。

## 选写与取舍

读完整相关原文，先判断事件主线，再列关键细节、影响理解的条件、必要背景及无关枝节。一篇文章有多个重点时分别判断；一个槽位保持一个主要事件，可由多个事实点解释。不能只摘最容易定锚日期的一句。

矩阵每条填写source_outline：event_type、reader_context、industry_relation=direct、industry_value_after_dedup、points。points各项含id、text、role（main/key/condition/background/nonessential）、evidence、decision（included/excluded）、atom_ids。纳入点映射正文原子；排除点无atom_ids，必须写exclusion_kind（duplicate/outside_event/nonessential/unsupported）及reason。关键点待核时继续补证，不以短句代替完整判断。主线不得被排除后继续占用槽位。

原文支持不等于必须照抄。重复、口号、无关背景和无据参数应排除；有关键价值但暂缺证据时先补证，必要时换题。删去历史重复后，重新检查剩余主线是否足够有价值。不得靠配色轮圈、空泛表态或同义复述维持槽位。

政策及市场条目须直接关联汽车生产、销售、进出口、产品与技术准入、供应链、渠道售后或汽车经营。仅涉及道路、行人、公交线路的城市新闻不自动合格；重点国家fallback也不能豁免产业关联要求。

## 按事件类型检查

| 类型 | 应主动核查的必要信息 |
|---|---|
| 产品 | 市场、车型、阶段、商业节点；体现差异的动力或技术、价格与交付计划；产地如有业务意义 |
| 技术／产业化 | 主体关系、研发制造对象、规模单位、关键能力、应用车型或客户、阶段 |
| 制造投资 | 投什么、地点与主体、总量和新增区别、产能或岗位、建设投产阶段 |
| 召回 | 车型年款市场、车或零件数量口径、缺陷影响、处置阶段 |
| 政策 | 发布机构、直接适用汽车对象、具体变化、程序时间、范围和例外 |
| 数据 | 新发布事件日与统计期分开、数值单位、范围、基期及覆盖限制 |

以上为阅读提示，不是要求填满所有参数；源文没有、无助理解或已刊的内容不强加。mph、km/h以及hp、PS等单位严格保留或有据换算，不能按相似数字替换。

## 审核与修订

逐条review除原十项外，增加key_point_coverage（来源重点逐点处理）、reader_context（对象范围和条件足以理解）、industry_value_after_dedup（删除重复后仍有直接汽车业务价值）。全稿QA增加source_to_draft：从来源回看成稿，检查关键遗漏；与稿件回源查错同时进行。不能只重读已选atoms就签核来源重点完整。

机器只校验信息点、摘录、取舍和映射结构，不自动证明原文所有重点已列出、排除合理或新闻真实。结构完整、事实核准、重点充分、新闻价值、人工终审分别判断。

带“人工审核：”的文件先保存原文及哈希。修订只回写唯一矩阵，留存每条批注处理结果；重做受影响的证据、历史、跨栏、双语与摘要，再执行review、全稿QA、validate、build。build保留带批注旧稿后生成新送审稿，始终等待真实人工终审。

双版本正文仅渲染atoms。来源、日期、口径和归因如需出现，必须先进入已核atoms；排版层禁止补事实或按旧日期／槽位替换文字。
